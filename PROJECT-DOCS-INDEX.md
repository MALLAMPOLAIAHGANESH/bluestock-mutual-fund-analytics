# Project Documentation Index

This documentation pack describes the Bluestock Mutual Fund Analytics platform from four perspectives.

| File | Purpose |
|---|---|
| `agents.md` | Rules and working guide for developers/AI coding agents |
| `architecture.md` | Technical system, data, API and deployment architecture |
| `design-system.md` | UI/UX, visual tokens, components and interaction rules |
| `product-requirements-document.md` | Product goals, users, features and acceptance criteria |

## Recommended reading order

```text
PRD
 ↓
Architecture
 ↓
Design System
 ↓
Agents
 ↓
Implementation
```

The documents are intentionally written so a new developer can understand the project without first reading the entire repository.
